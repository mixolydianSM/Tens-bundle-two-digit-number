# 십 묶음 놀이터

두 자릿수를 **십 묶음(십 막대)과 낱개**로 만들고, 수의 순서를 익히고, 두 수의 양을 그림으로 비교하는 수학 놀이입니다.
특수교육(중증 발달장애) 학생을 위해 큰 버튼, 음성 안내, 오류 없는 학습 방식으로 만들었습니다.

## 활동
1. **수 만들기**: 십 막대와 낱개를 놓아 수를 만들어요. 낱개 10개는 '묶기'로 십 막대 1개가 돼요.
2. **숫자 기차**: 빈 칸에 들어갈 수를 찾아요. 1씩 / 10씩.
3. **누가 더 많을까**: 두 수를 그림으로 보고 많은 쪽(또는 적은 쪽)을 골라요.
4. **만들어서 비교**: 직접 만든 수를 친구 수와 비교해요. 미션 / 자유.

## 사용 기술
- 그림 테마: 블록 · 젤리 · 초콜릿 (첫 화면 설정)
- Web Speech API (한국어 음성 안내). 기기에 한국어 TTS 음성이 있어야 해요.
- Web Audio API (효과음)
- 별도 설치 없이 `index.html` 하나로 동작해요.
